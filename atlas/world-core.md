# 세계의 근원과 월드코어

세계의 근원은 다섯 직업의 장기 목표를 하나로 모으는 엔드게임 아이템입니다. 정령석과는 별개의 계열이며 일반 가공대·조립대 제작 목록에는 나타나지 않습니다.

2026년 9월 11일 LIVE 운영본에는 세계의 근원 5종과 월드코어 1종이 아이템으로 등록되어 있습니다. 다만 현재 플레이어용 제단 위치가 비어 있고 최근 아이템 식별 체계 변경 뒤 보상 지급까지 인게임 재검수가 끝나지 않았으므로, 운영 공지 전에는 완전 개방 콘텐츠로 보지 않습니다.

## 반복 획득 구조

- 농부는 귀속된 `순환의 특수 씨앗`을 자기 섬의 3×3 커스텀 경작지에 심고, 농부 XP 1,000으로 성장시켜 수확합니다.
- 광부는 반복 해금 뒤 얻은 광부 XP를 포인트로 쌓으며, 현재 10,000포인트마다 대지의 심장 1개를 수령하도록 설정되어 있습니다.
- 가공사는 무지개빛 비약을 제작할 때 융화의 물방울을 추가로 얻습니다. 현재 기본값은 10% 확률이며 10회 천장이 적용됩니다.
- 기술자는 기술대에서 실제 소비한 연료 시간을 포인트로 쌓으며, 현재 3,600초마다 문명의 불씨 1개를 수령하도록 설정되어 있습니다.
- 방랑가 반복 획득은 아직 운영 런타임에 연결되지 않았습니다.

반복 획득 수치는 임시 밸런스 값입니다.

## 월드코어

월드코어는 다섯 세계의 근원을 각각 1개씩 응축하는 엔드게임 강화 재료입니다.

| 필요한 아이템 | 수량 |
| --- | ---: |
| 순환의 씨앗 | 1개 |
| 대지의 심장 | 1개 |
| 융화의 물방울 | 1개 |
| 문명의 불씨 | 1개 |
| 바람의 숨결 | 1개 |

월드코어 제작은 일반 조립 레시피가 아니라 전용 월드와 제작 제단을 사용하는 별도 흐름입니다. 현재 이동·제작·강화 제단의 플레이어 이용 경로는 아직 열리지 않았습니다.

## 월드코어 강화 결과

| 입력 | 강화 결과 |
| --- | --- |
| 농산물 창고 IV + 월드코어 | 무한 농산물 창고 |
| 광물 창고 IV + 월드코어 | 무한 광물 창고 |
| 스프링클러 IV + 월드코어 | 무한 스프링클러 |

무한 농산물·광물 창고는 해당 저장소를 사실상 무한 용량으로 바꾸는 모듈입니다. 무한 스프링클러는 물과 내구도를 소모하지 않고 IV보다 넓게 급수하도록 정의되어 있습니다. 세 강화는 제단 개방과 최종 인게임 검수 뒤 이용하는 콘텐츠입니다.
