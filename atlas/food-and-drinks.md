# 음식·음료 도감

요리 25종과 음료 29종의 제작 조건을 확인하세요. 수치는 2026년 9월 11일 확인 기준입니다.

## 요리 25종 <a href="#cooking" id="cooking"></a>

요리는 가공사의 성장 단계에 따라 다섯 묶음으로 열립니다. 모든 요리는 현재 한 번 제작할 때 가공 시설의 물 50을 사용합니다.

| 단계 | 조건 | 제작 시간 | 음식 |
| --- | --- | ---: | --- |
| 기본 | 가공사 1레벨 | 3초 | 맥주, 블루베리잼, 오이피클, 딸기잼, 와인 |
| 간단 | 가공사 3레벨 | 4초 | 보리죽, 콩 스튜, 코울슬로, 옥수수 수프, 오이 샐러드, 양파 수프, 토마토 스파게티 |
| 일반 | 가공사 5레벨 | 5초 | 블루베리 머핀, 양배추 고기말이, 치킨버거, 치킨파이, 햄버거, 양고기 꼬치구이, 미트파이, 믹스드 그릴, 딸기잼 토스트 |
| 복합 | 가공사 8레벨 | 6초 | 비프 부르기뇽, 믹스베리 타르트, 호박 그라탱 |
| 고급 | 가공사 10레벨 | 8초 | 피자 |

## 바리스타 음료 29종 <a href="#drinks" id="drinks"></a>

음료는 가공사 50레벨에 바리스타 기능을 연 뒤 만들 수 있습니다. 한 번 제작할 때 시설의 물 50을 사용합니다. 물병을 재료 칸에 넣는 방식은 아닙니다.

| 제작 시간 | 음료 |
| ---: | --- |
| 10초 | 커피, 캐모마일 티, 히비스커스 티, 자스민 티, 라벤더 티, 레몬그라스 티, 페퍼민트 티, 로즈힙 티, 로즈마리 티 |
| 30초 | 보리 커피, 블루베리 에이드, 포도 에이드, 히비스커스 에이드, 레몬그라스 아이스티, 민트 아이스티, 로즈힙 에이드, 딸기 에이드 |
| 60초 | 플라워 블렌드, 가든 블렌드, 황금 곡물 커피, 자스민 로즈 티, 민트 블렌드, 문라이트 티, 레드 블렌드 |
| 90초 | 오색 과일에이드, 황금 수확제 커피, 한여름 청량수, 달빛 정원차, 석양빛 과일 화채 |

## 품질 <a href="#quality" id="quality"></a>

음식과 음료는 품질을 가질 수 있습니다. 사용한 작물의 품질은 결과를 그대로 확정하지 않고 결과 품질 확률을 높이는 방향으로 작용합니다. 레시피 숙련과 제작 중 요구되는 행동도 결과에 영향을 줄 수 있습니다.

## 재료 찾기 <a href="#ingredients" id="ingredients"></a>

수확한 작물로 무엇을 만들 수 있는지는 [작물 도감](crops.md)에서 확인하세요. 고기나 설탕이 함께 필요한 요리도 있습니다. 정확한 재료와 수량은 `/가공도감`에 표시됩니다.

## 제작 전 확인 <a href="#before-crafting" id="before-crafting"></a>

- 현재 가공 시설이 요리 또는 바리스타 품목을 지원하는지 확인합니다.
- 가공사의 레벨과 바리스타 전문 해금 상태를 확인합니다.
- 정품 작물과 요구된 일반 재료를 정확한 수량으로 준비합니다.
- 시설에 물이 남아 있는지 확인합니다.
- 완성된 결과물을 직접 수령합니다.
