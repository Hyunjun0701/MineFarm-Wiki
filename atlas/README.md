## 제작이 처음이라면

{% stepper %}
{% step %}
### 필요한 시설 확인

요리·제련·세공은 가공 시설을, 기술 부품과 완제품은 기술대를 사용합니다.
{% endstep %}
{% step %}
### 재료와 사용 조건 확인

게임 안 제작 목록에서 재료 수량과 잠금 표시를 확인하세요. 이름이 비슷한 다른 아이템은 재료로 사용할 수 없을 수 있습니다.
{% endstep %}
{% step %}
### 제작 후 결과물 수령

물이나 연료를 채우고 제작을 시작하세요. 완료된 결과물은 해당 시설에서 수령합니다.
{% endstep %}
{% endstepper %}

[레시피와 제작 조건 자세히 보기](recipes.md)

{% hint style="info" %}
문서의 수치는 각 페이지에 적힌 확인 날짜 기준입니다. 게임 안 설명과 다르면 현재 게임 화면을 먼저 확인하세요.
{% endhint %}

기본 도구와 펫은 [메뉴·편의 기능](../guides/README.md)에서 안내합니다.
