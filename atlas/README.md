# 아이템 도감

아이템 도감은 이름, 분류, 획득처와 사용처를 서로 연결해 찾을 수 있도록 구조화 데이터로 관리합니다.

## 공개 기준

* 실제 서버에서 존재와 이름을 확인한 아이템
* 획득처와 사용처를 확인한 아이템
* 거래·귀속·제한 정보를 검토한 아이템
* Moon이 공개를 승인한 아이템

검증되지 않은 아이템은 검색 결과와 도감 목록에 표시하지 않습니다.

## 준비 중인 분류

* 작물
* 광물
* 채집물
* 가공 재료와 가공품
* 기술 제품
* 도구
* 소비 아이템
* 화폐와 특수 재화
* 퀘스트 관련 아이템

첫 데이터 검증이 완료되면 이 페이지에 분류별 목록과 개별 아이템 문서가 자동 생성됩니다.
