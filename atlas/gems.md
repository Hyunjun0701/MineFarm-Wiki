# 보석·정령석 도감

MineValley의 보석 계열은 하위 보석 8종, 직업 속성을 나타내는 정령석 6종과 월별 탄생석 12종으로 이루어집니다. 현재 26종 모두 품질 추첨 없이 고정 품질로 제작됩니다.

아래 제작법은 2026년 9월 11일 확인 기준입니다. 보석 제작 1회에는 시설 물 60이 필요합니다.

## 사용처 <a href="#uses" id="uses"></a>

하위 보석은 정령석과 탄생석의 재료가 되며, 세공에서는 반지·귀걸이·목걸이·팔찌와 브로치 제작에 사용됩니다. 정령석은 직업 속성 장신구와 마도공학 계열 제작에 연결됩니다.
