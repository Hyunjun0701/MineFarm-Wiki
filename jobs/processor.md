# 가공사

가공사는 작물과 광물 같은 원재료를 음식, 산업 재료와 더 높은 가치의 제품으로 바꾸는 직업입니다.

![요리와 보석 가공을 함께 보여 주는 가공사의 직업 메뉴 원화](../assets/images/jobs/processor.png)

{% hint style="success" %}
**이런 생활을 좋아한다면**

재료를 모아 요리부터 장신구까지 직접 완성하는 즐거움을 느껴 보세요.
{% endhint %}

## 처음 할 일

{% stepper %}

{% step %}
### 레시피 선택

`/가공도감`에서 현재 이용 가능한 품목 하나를 고릅니다.
{% endstep %}

{% step %}
### 재료 준비

해당 품목을 지원하는 가공대와 필요한 재료·수량을 확인합니다.
{% endstep %}

{% step %}
### 가공 후 완성품 수령

재료를 투입해 제작을 시작하고, 완료 후 결과물을 수령합니다.
{% endstep %}

{% endstepper %}

시설에 따라 물도 필요합니다. 첫 제작은 [가공 안내](../world/processing.md)의 순서를 따라가세요.

## 핵심 활동

- 가공 도감에서 레시피와 현재 사용 가능 상태 확인
- 가공대에 재료를 넣고 시간 기반 제작 진행
- 요리·제빵·음료와 제련 계열 생산
- 레시피별 숙련과 품질 성장
- 세공을 통한 장신구 제작과 활용

## 성장 방향

가공을 반복하면 직업 경험치와 레시피별 숙련으로 이어집니다. 품질은 완성품의 가치나 후속 효과에 영향을 줄 수 있으며, 품목마다 같은 방식으로 적용되는 것은 아닙니다.

직업 레벨과 레시피 숙련은 구분해서 확인하세요. 공통 성장 규칙은 [직업 성장 방식](growth.md), 품목별 제작 조건은 [레시피 안내](../atlas/recipes.md)에서 설명합니다.

## 다음 생산 단계

가공품은 직접 사용할 수도 있고, 상점·유저거래소·주문소·주민과 섬 퀘스트에 활용할 수도 있습니다. 모든 품목이 모든 판매 경로를 가지지는 않습니다.

합금과 판재 같은 중간재는 기술자의 부품·설비 제작으로 이어집니다. 작물은 농부에게, 광물은 광부에게 구하는 등 다른 플레이어와 생산을 나눌 수도 있습니다.
