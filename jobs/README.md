# 직업과 성장

MineFarm에는 다섯 개의 주 직업이 있습니다.

| 직업 | 이런 플레이어에게 잘 맞아요 | 핵심 재미 |
|---|---|---|
| [농부](farmer.md) | 넓은 생산 공간과 수확 동선을 키우고 싶어요 | 밭, 수확, 작물 관리 |
| [광부](miner.md) | 안정적으로 광물을 모으고 저장을 성장시키고 싶어요 | 채광, 잠광, 광물창고 |
| [가공사](processor.md) | 재료를 새로운 기능과 가치가 있는 제품으로 바꾸고 싶어요 | 레시피, 가공, 숙련 |
| [상인](merchant.md) | 수요를 읽고 거래를 연결해 이익을 만들고 싶어요 | 정보, 조달, 거래와 판로 |
| [기술자](technician.md) | 부품을 조립하고 편의 제품과 공방을 키우고 싶어요 | 조립, 제품, 자동화 기반 |

## 선택하기 전에

- 처음부터 직업을 고를 필요는 없습니다.
- 전직 전에도 여러 기본 활동을 체험할 수 있습니다.
- 직업은 다른 활동을 금지하지 않습니다.
- 직업은 해당 분야의 성장 한계와 전문적인 선택을 넓혀 줍니다.

직업별 상세 레벨, 스킬 수치와 승급 조건은 확인이 끝난 정보부터 각 문서에 추가합니다.
