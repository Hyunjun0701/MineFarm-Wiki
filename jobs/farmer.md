# 농부

농부는 작물을 기르고 수확하며 밭의 생산성과 편의 기능을 성장시키는 직업입니다.

![밭과 수확하는 농부를 그린 직업 메뉴 원화](../assets/images/jobs/farmer.png)

{% hint style="success" %}
**이런 생활을 좋아한다면**

씨앗 하나에서 시작해 나만의 밭을 키우고 싶은 분께 잘 맞아요.
{% endhint %}

## 처음 할 일

{% stepper %}

{% step %}
### 밭과 씨앗 준비

재배 가능한 밭, 씨앗과 물을 준비합니다.
{% endstep %}

{% step %}
### 심고 물 주기

씨앗을 심은 뒤 밭에 물을 주고 성장 상태를 확인합니다.
{% endstep %}

{% step %}
### 수확 후 사용처 정하기

다 자란 작물을 수확하고 보관·가공·판매 중 다음 사용처를 정합니다.
{% endstep %}

{% endstepper %}

첫 재배는 [농사 안내](../world/farming.md)를 따라가고, 키울 작물은 [작물 도감](../atlas/crops.md)에서 골라 보세요.

## 핵심 활동

- 기본 작물과 MineValley 커스텀 작물 재배
- 수확을 통한 직업 경험치 획득
- 농작물창고를 이용한 생산물 관리
- 수확량과 생산 동선을 개선하는 성장
- 자동심기·자동줍기 등 농사 편의 기능과의 연결

## 성장 방향

농부의 성장은 작물 종류, 수확 방식, 씨앗과 물 관리, 자동화 지원처럼 밭을 운영하는 방법을 넓혀 갑니다. 허브와 전문 기능은 현재 해금 조건을 확인한 뒤 이용하세요.

공통 성장 규칙과 스킬트리·해금 스킬의 차이는 [직업 성장 방식](growth.md)에서 확인할 수 있습니다.

## 도구와 보관

스프링클러, 성장 알리미와 허수아비는 밭 운영에 쓰이는 농업 설비입니다. 설치 전에 제품 설명에서 범위와 조건을 확인하세요. 단계별 제작법은 [기술 완제품 도감](../atlas/technical-products.md)에 정리되어 있습니다.

### 농작물창고

농작물창고는 농부만의 인벤토리가 아니라 모든 플레이어가 사용할 수 있는 농사 기반 시설입니다. 지원되는 작물은 수확과 보관 흐름에 연결되며, 필요할 때 꺼내 가공하거나 납품할 수 있습니다.

## 다음 생산 단계

작물은 직접 판매할 수도 있지만, 가공사의 요리·제빵·음료 재료나 주민·섬 퀘스트의 납품품, 다른 플레이어의 주문품이 될 수 있습니다.
