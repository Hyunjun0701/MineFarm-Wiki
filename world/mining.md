# 광산과 잠광

무한광산에서는 광석을 직접 캐고, 온라인 잠광에서는 접속한 동안 광물을 모읍니다. 두 활동 모두 광부 경험치를 얻을 수 있지만 시작 방법과 보관 장소가 다릅니다.

## 무한광산

무한광산은 개인 섬에서 실제 광석 블록을 직접 캐는 활동입니다. 직접 캔 아이템은 플레이어가 획득하며, 잠광 산출물처럼 자동으로 광물창고에 저장되는 것은 아닙니다.

광부가 아니어도 기본 채광은 할 수 있습니다. 광부는 성장하면서 채광 효율과 광산 안에서 선택할 수 있는 활동을 넓혀 갑니다.

## 온라인 잠광

온라인 잠광은 서버에 접속한 동안 광물을 모으는 활동입니다. 곡괭이 상태와 시작 조건을 확인하고 `/잠광`을 입력하세요. 끝낼 때는 `/잠광종료`를 입력해 모은 광물을 정산합니다.

- `/잠광` — 온라인 잠광 시작
- `/잠광상태` — 현재 진행 상태 확인
- `/잠광종료` — 잠광 종료 및 정산
- `/잠광표시` — 잠광 표시 설정 확인·변경

접속을 종료한 동안에도 계속 생산되는 방치형 채굴은 아닙니다.

2026년 9월 11일 기준 잠광은 60초 단위로 진행되며, 곡괭이 6단계와 광물 산출표 8종을 사용합니다. 실제 산출량은 장비와 직업 성장, 적용 중인 효과에 따라 달라질 수 있습니다.

## 광물창고

잠광을 끝내면 모은 광물이 광물창고로 들어갑니다. 창고가 가득 차면 더 모으지 못할 수 있으므로 시작 전에 남은 공간을 확인하세요.

`/광물창고`로 전용 저장 공간을 열 수 있습니다. 직접 채광한 아이템과 잠광 산출물의 이동 경로를 서로 혼동하지 않는 것이 중요합니다.

## 광맥과 유물

광부가 성장하면 광맥 활동과 유물 탐색을 할 수 있습니다. 광맥은 일반 잠광과 따로 진행하므로 상태 확인과 종료에도 전용 명령을 사용하세요.

- `/광맥상태` — 광맥 진행 상태 확인
- `/광맥종료` — 진행 중인 광맥 활동 종료

발견한 유물의 이름과 설명은 게임 안에서 확인하세요.

## 채광물이 쓰이는 곳

광물로 압축 재료, 합금, 보석과 장신구, 기술 부품과 설비를 만들 수 있습니다. 필요한 재료는 남겨 두고, 팔 물건은 [주민 상점](../economy/npc-shops.md#first-sale)에서 취급하는지 확인하세요.
