# 광산과 잠광

MineValley의 채광은 직접 광석을 캐는 무한광산과, 접속 중 진행하는 온라인 잠광으로 나뉩니다. 두 활동은 같은 광부 성장에 연결되지만 진행 방법과 산출물 보관 장소가 다릅니다.

## 무한광산

무한광산은 개인 섬에서 실제 광석 블록을 직접 캐는 활동입니다. 직접 캔 아이템은 플레이어가 획득하며, 잠광 산출물처럼 자동으로 광물창고에 저장되는 것은 아닙니다.

광부가 아니어도 기본 채광은 할 수 있습니다. 광부는 성장하면서 채광 효율과 광산 안에서 선택할 수 있는 활동을 넓혀 갑니다.

## 온라인 잠광

온라인 잠광은 서버에 접속한 상태에서 가상 채굴을 진행하는 별도 활동입니다. 사용 중인 곡괭이 상태와 잠광 조건을 확인한 뒤 시작하며, 종료할 때까지의 결과를 정산합니다.

- `/잠광` — 온라인 잠광 시작
- `/잠광상태` — 현재 진행 상태 확인
- `/잠광종료` — 잠광 종료 및 정산
- `/잠광표시` — 잠광 표시 설정 확인·변경

접속을 종료한 동안에도 계속 생산되는 방치형 채굴은 아닙니다.

2026년 9월 11일 LIVE 운영본에서 잠광은 60초 단위로 진행되며, 곡괭이 6단계와 광물 산출표 8종을 사용합니다. 실제 산출량은 장비와 직업 성장, 적용 중인 효과에 따라 달라질 수 있습니다.

## 광물창고

잠광 산출물은 정산 과정에서 광물창고로 들어갑니다. 창고가 가득 차면 추가 생산이나 관련 보상이 정상적으로 이어지지 않을 수 있으므로 시작 전에 남은 공간을 확인하세요.

`/광물창고`로 전용 저장 공간을 열 수 있습니다. 직접 채광한 아이템과 잠광 산출물의 이동 경로를 서로 혼동하지 않는 것이 중요합니다.

## 광맥과 유물

성장 후에는 일반 잠광과 구분되는 광맥 활동과 유물 관련 콘텐츠가 연결됩니다. 광맥은 독립된 진행 상태를 가지므로, 중단하거나 상태를 확인할 때도 광맥 전용 명령을 사용합니다.

- `/광맥상태` — 광맥 진행 상태 확인
- `/광맥종료` — 진행 중인 광맥 활동 종료

현재 유물 10종의 발견 판정과 세공 보관소 연결이 운영되고 있습니다. 유물의 종류, 발견 조건과 쓰임은 별도 도감에서 자세히 설명합니다.

## 채광물이 쓰이는 곳

광물은 압축 재료, 합금, 보석과 장신구, 기술 부품과 설비 제작으로 이어집니다. 광부가 원재료를 공급하면 가공사와 기술자가 더 높은 단계의 제품으로 연결하는 구조입니다.
