# 가공

가공으로 작물과 광물을 음식, 음료, 산업 재료와 장신구로 만들 수 있습니다. 품목에 맞는 시설과 재료를 준비하고, 완성품은 직접 수령하세요.

| 시작 전에 | 확인할 내용 |
| --- | --- |
| 준비할 것 | 만들 품목을 지원하는 가공 시설, 레시피 재료와 필요한 물 |
| 먼저 열 화면 | `/가공도감` |
| 첫 목표 | 이용 가능한 품목 하나를 만들고 완성품 수령 |

2026년 9월 11일 기준 가공 레시피는 135종입니다. 현재 만들 수 있는 품목은 `/가공도감`에서 확인하세요.

## <i class="fa-compass">:compass:</i> 시작하기 <a href="#시작하기" id="시작하기"></a>

{% stepper %}
{% step %}
### 품목과 시설 고르기

`/가공도감`에서 만들 수 있는 품목을 고르고, 해당 품목을 지원하는 가공 시설을 찾습니다.
{% endstep %}
{% step %}
### 재료와 물 준비

레시피에 표시된 아이템과 수량을 준비합니다. 물이 필요한 시설이라면 남은 물도 확인하세요.
{% endstep %}
{% step %}
### 제작 시작

시설에 재료를 넣고 가공을 시작합니다. 화면에서 진행 상태와 남은 시간을 확인하세요.
{% endstep %}
{% step %}
### 완성품 수령

제작이 끝나면 시설에서 완성품을 수령합니다.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
재료를 넣었다고 바로 완성품이 지급되는 것은 아닙니다. 진행 중인 시설에 같은 행동을 반복하기 전에 현재 상태와 결과물 수령 여부를 확인하세요.
{% endhint %}

## 주요 가공 분야

| 분야 | 대표 결과물 |
| --- | --- |
| 식품 가공 | 요리, 제빵, 작물 기반 식품 |
| 음료 가공 | 커피와 허브를 활용한 음료 |
| 광물 가공 | 광물 압축품, 제련품과 합금 |
| 보석 가공 | 보석, 영석과 탄생석 계열 재료 |
| 세공 | 가공된 재료를 이용한 장신구 |

같은 재료라도 모든 시설에서 사용할 수 있는 것은 아닙니다. 정확한 조합은 가공 도감과 해당 시설 화면에서 확인하세요.

## 물과 시설 상태

일부 가공 시설은 제작 재료 외에 물을 필요로 합니다. 제작이 시작되지 않으면 레시피 재료뿐 아니라 시설의 물 보유 상태도 함께 확인하세요.

## 숙련과 품질

가공을 반복하면 직업 경험치와 레시피별 숙련이 쌓입니다. 품질이 적용되는 결과물은 거래 가치나 후속 사용처가 달라질 수 있습니다. 모든 가공품에 같은 품질 규칙이 적용되는 것은 아닙니다.

## 세공

세공은 보석과 금속 재료로 장신구를 만드는 활동입니다. `/세공`에서 장신구 36종을 살펴볼 수 있고, 장신구는 최대 2개까지 장착할 수 있습니다. 제작 재료, 고유 효과와 잠재능력은 [장신구 도감](../atlas/accessories.md)에서 확인하세요.

## 만들 수 없을 때

- 가공 도감에서 아직 잠긴 품목인지 확인합니다.
- 현재 시설이 그 품목을 지원하는지 확인합니다.
- 이름만 비슷한 재료가 아니라 레시피에 표시된 아이템인지 확인합니다.
- 필요한 수량, 물과 시설 상태를 확인합니다.
- 이전 작업의 완성품을 먼저 수령해야 하는지 확인합니다.

## <i class="fa-route">:route:</i> 완성품을 받은 다음에는
