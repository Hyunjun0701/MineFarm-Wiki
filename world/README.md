# 세계와 생활

MineFarm의 활동은 개인 섬과 스폰을 비롯한 여러 공간에서 이어집니다.

## 주요 공간

### 개인 섬

기본 생활, 생산과 섬 활동의 중심입니다. 섬원과 함께 운영할 수 있으며 섬 기여도와 주간 목표에 참여할 수 있습니다.

### 스폰과 마을

NPC, 상점, 거래와 공공 활동을 만나는 중심 공간입니다.

## 생활 활동

- 농사
- 채광
- 가공과 제작
- 벌목
- 낚시

각 활동이 모두 독립된 주 직업은 아닙니다. 농사와 채광은 주요 생산 직업과 직접 연결되고, 벌목과 낚시는 누구나 즐길 수 있는 공통 생활 활동입니다.
