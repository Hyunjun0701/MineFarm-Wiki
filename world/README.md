## 주요 공간

### 개인 섬

농사와 기본 생산, 섬원 활동의 중심입니다. 내 섬 화면에서 이동과 섬 정보, 주간 기여도와 섬 퀘스트를 확인할 수 있습니다.

### 마을

상점과 주요 시설, NPC와 공공 활동을 만나는 중심 공간입니다. 기능을 제공하는 상점 NPC와 관계를 맺는 주민은 서로 다른 역할을 가집니다.

### 생산 시설

원재료를 음식과 산업 재료, 기술 제품으로 바꾸는 공간입니다. 일부 시설과 레시피는 직업 성장이나 해금 조건과 연결됩니다.
