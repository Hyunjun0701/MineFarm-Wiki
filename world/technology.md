# 기술 설비

기술 설비는 재료와 부품을 기능성 제품으로 조립하고, 여러 장치를 생산 라인으로 연결하는 콘텐츠입니다. 기술자는 성장하면서 더 높은 단계의 조립대와 설비를 다룰 수 있습니다.

2026년 9월 11일 LIVE 운영본에는 기술 아이템 81종과 조립 레시피 72종이 연결되어 있습니다. 구성은 중간재 27종, 기술대·기반 설비 7종, 완제품 41종, 세계의 근원과 월드코어 6종입니다.

## 조립대

조립대는 제품을 선택하고 재료를 투입해 시간 기반으로 완성하는 작업 공간입니다. 기본 단계에서 시작해 증기·전기·마도공학 계열로 확장되며, 조립대마다 다룰 수 있는 제품과 운용 부담이 다릅니다.

1. 조립대에서 제품과 필요한 재료를 확인합니다.
2. 가공품과 부품을 준비해 투입합니다.
3. 조립을 시작하고 진행 상태를 확인합니다.
4. 완료된 제품을 직접 수령합니다.

## 생산 라인

생산 라인은 조립대와 공급 설비를 연결해 재료와 연료가 이동하도록 구성합니다. `/라인` 또는 `/기술자라인`을 사용해 바라보는 작업대의 연결 상태를 확인할 수 있습니다.

라인은 설치만으로 모든 생산을 대신하지 않습니다. 제품에 맞는 작업대, 올바른 연결, 충분한 재료와 에너지가 모두 필요합니다.

## 설계도

일부 기술 제품과 설비는 설계도 체계와 연결됩니다. `/설계도`에서 현재 확인할 수 있는 설계도 정보를 열 수 있습니다. 아직 공개되지 않은 제품군은 설계도가 보이더라도 실제 제작 가능 여부가 다를 수 있으므로 조립대 화면을 함께 확인하세요.

## 기술 제품의 역할

| 역할 | 예시 |
| --- | --- |
| 저장 확장 | 농작물·광물 생산물을 위한 확장 설비 |
| 농사 지원 | 스프링클러, 작물 상태 알림과 생활 편의 |
| 생산 지원 | 고성능 용광로와 가공 보조 설비 |
| 자동화 이용권 | 자동줍기·자동심기 기능과 연결되는 제품 |
| 라인 구성 | 재료·연료 공급과 연결에 쓰이는 부품·장치 |

제품별 정확한 제작 재료와 현재 성능은 [기술 재료·부품 도감](../atlas/technical-components.md), [기술대·기반 설비 도감](../atlas/technical-facilities.md), [기술 완제품 도감](../atlas/technical-products.md)에서 확인할 수 있습니다.

현재 설비 런타임에는 상자 정리 장치, 자동 블록 압축기, 고성능 화로와 자동 제작대가 설치형 장비로 연결되어 있습니다. 자동 파종기·자동 수거기는 충전형 제품으로, 농산물·광물 창고는 순차 확장 모듈로 동작합니다. 스프링클러·재배 알리미·허수아비도 농업 설비에 연결됩니다.

## 설비가 작동하지 않을 때

1. 현재 조립대가 선택한 제품을 지원하는지 확인합니다.
2. 필요한 정품 재료와 중간 부품이 모두 있는지 확인합니다.
3. 재료통·연료통을 포함한 공급 상태를 확인합니다.
4. 라인이 올바른 방향과 대상으로 연결됐는지 확인합니다.
5. 이미 완료된 결과물을 먼저 수령해야 하는지 확인합니다.

설비를 바로 부수거나 옮기기 전에 이 순서로 상태를 확인하는 것이 안전합니다.
