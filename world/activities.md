# 주요 활동

| 활동 | 무엇을 하나요? | 함께 살펴볼 것 |
| --- | --- | --- |
| 농사 | 작물을 심고 수확해 생산량을 키웁니다 | 농부, 농작물창고, 음식, 퀘스트 |
| 채광 | 직접 채광하거나 온라인 잠광으로 광물을 모읍니다 | 광부, 광물창고, 제련, 기술 제작 |
| 가공 | 원재료를 음식·가공품·산업 재료로 바꿉니다 | 가공사, 레시피 숙련, 장신구 |
| 기술 제작 | 부품을 조립하고 설비와 생산 라인을 운용합니다 | 기술자, 편의 제품, 자동화 |
| 거래 | 생산품을 사고팔거나 필요한 물건을 주문합니다 | 상점, 유저거래소, 공개·개인 주문 |
| 마을 활동 | 섬원과 납품하고 주간 목표에 기여합니다 | 섬 퀘스트, 마을 단계, 랭킹 |
| 주민 교류 | 주민을 발견하고 관계와 퀘스트를 이어 갑니다 | 대화, 선물, 주민 퀘스트 |

수확한 작물로 음식을 만들고, 캔 광물로 기술 부품을 만들 수 있습니다. 완성품을 직접 쓰거나 팔고 싶다면 [생산과 수요의 연결](production-chain.md)에서 사용처를 살펴보세요.

정확한 획득량, 가격, 확률과 성장 수치는 현재 게임 화면을 기준으로 확인하세요.
