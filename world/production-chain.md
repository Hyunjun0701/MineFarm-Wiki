# 생산과 수요의 연결

MineValley의 아이템은 `얻고 바로 판매하기`에서 끝나지 않습니다. 원재료가 여러 직업과 시설을 거쳐 다른 기능과 수요로 이어집니다.

## 기본 생산 사슬

```text
농부의 작물 ──→ 요리·제빵·음료 ──┐
                                  ├─→ 상점·주문·퀘스트·마을 수요
광부의 광물 ──→ 제련·산업 재료 ──┤
                                  └─→ 기술 제품·설비·월드코어
```

## 1. 원재료 모으기

농사는 작물과 농사 재료를, 채광은 광물과 광산 관련 재료를 공급합니다. 생산물은 전용 창고에 쌓거나 다음 제작 단계로 옮길 수 있습니다.

## 2. 가공하기

가공사는 요리, 제빵, 음료, 제련과 여러 중간재를 만듭니다. 레시피마다 사용 가능 조건과 숙련 상태가 다를 수 있으며, 가공 도감에서 확인할 수 있습니다.

## 3. 조립하고 설비 운용하기

기술자는 가공된 부품과 재료를 조립해 편의 제품과 설비를 만듭니다. 성장하면 생산 라인, 재료·연료 공급과 더 높은 단계의 기술 제작으로 이어집니다.

## 4. 필요한 곳에 공급하기

| 경로 | 특징 |
| --- | --- |
| 주민 상점 | 가장 쉽게 이용할 수 있는 기준 판매처 |
| 유저거래소 | 판매자가 물품과 가격을 정하는 자유시장 |
| 주문소 | 구매자가 원하는 물품과 보상을 먼저 제시 |
| 개인 주문 | 조건을 충족한 방랑가가 특정 공급자와 만드는 1:1 주문 |
| NPC 퀘스트 | 주민의 상황과 관계에 연결된 제한 수요 |
| 섬·마을 수요 | 섬원과 함께 납품해 공동 진행과 기여를 만드는 수요 |

모든 아이템이 모든 경로에서 판매되거나 납품되는 것은 아닙니다. 거래 또는 납품 화면에 표시되는 허용 여부를 확인하세요.
