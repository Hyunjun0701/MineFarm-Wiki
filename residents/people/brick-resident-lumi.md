# 루미

차분한 어른처럼 보이고 싶어 하지만 좋아하는 것 앞에서는 기대와 설렘을 숨기지 못하는 마렌의 15살 딸.

![루미의 게임 리소스팩 초상화](../../assets/images/residents/brick-resident-lumi.png)

## 어떤 주민인가요?

| 구분 | 소개 |
| --- | --- |
| 생활 구역 | 벽돌 마을 |
| 역할 | 마을 주민들의 일을 구경하고 질문하며 배우는 어린 주민 |
| 성격 | 의젓해지고 싶은 마음, 단정함, 자기 취향, 설렘, 작은 고집, 솔직한 감정, 생활 속 배움 |

## 만나러 가기

루미의 기본 생활 구역은 벽돌 마을입니다. 주민은 하루 일정에 따라 이동하므로, 한 지점을 고정 위치로 생각하기보다 [마을 주민 안내](../README.md)를 참고해 생활 구역에서 찾아보세요.

대화를 걸면 현재 제공하는 기능을 확인할 수 있습니다. 대화·선물·퀘스트는 주민과 진행 상태에 따라 다르며, 실제 대화 화면의 안내를 따라 이용하세요.
