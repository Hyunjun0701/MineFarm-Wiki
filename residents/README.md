# 마을 주민

MineValley의 마을과 개인 섬에는 45명의 주민이 살고 있습니다. 농장과 공방에서 일하는 주민, 가게를 운영하는 주민, 마을을 거니는 이웃을 만나 보세요.

{% hint style="info" %}
주민은 집과 일터, 마을의 여러 장소를 오갑니다. 전에 만났던 자리에 없으면 주변을 둘러보세요.
{% endhint %}

## 마을에서 만날 얼굴들

[![글렌](../.gitbook/assets/farmer-glenn.png)](people/farmer-glenn.md) [![에린](../.gitbook/assets/hill-baker-erin.png)](people/hill-baker-erin.md) [![테오](../.gitbook/assets/hill-engineer-theo.png)](people/hill-engineer-theo.md) [![브란](../.gitbook/assets/hill-miner-bran.png)](people/hill-miner-bran.md)

이름을 누르면 주민의 소개와 초상화를 볼 수 있습니다. 아래 명단에서 45명을 생활 구역별로 찾아보세요.

## 주민을 만나는 방법

주민에게 말을 걸어 이야기를 나누어 보세요. 선물이나 퀘스트 등 이용할 수 있는 항목은 대화창에 표시됩니다. 주민마다 표시되는 항목은 다를 수 있습니다.

## 주민과 상점 NPC의 차이

| 구분        | 역할                          |
| --------- | --------------------------- |
| 주민 45명    | 마을과 개인 섬에서 생활하며 이야기를 나누는 이웃 |
| 상점 NPC 5명 | 작물·허브·광물·요리·음료를 다루는 상점 NPC  |

상점 NPC는 주민 수에 포함되지 않습니다.

## 생활 구역

언덕 마을에 22명, 벽돌 마을에 21명, 개인 섬에 2명이 생활합니다.

## 주민과 할 수 있는 일

* 새 이웃을 만나 이야기 나누기
* 선물하며 친해지기
* 주민의 부탁을 듣고 퀘스트 진행하기
* 직업, 생산과 거래에 관한 안내 받기

주민의 이야기는 직접 만나 천천히 알아가 보세요.
