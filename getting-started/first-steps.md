# 처음 10분

이번 목표는 **메뉴를 열고, 내 섬을 찾아, 첫 활동 하나를 시작하는 것**입니다. 수확이나 제작 완료까지 10분 안에 끝내야 한다는 뜻은 아닙니다.

{% stepper %}

{% step %}
### 메뉴부터 열어요

채팅에 `/메뉴`를 입력합니다. 글자와 그림이 정상적으로 보이면 다음 단계로 넘어가세요. 네모·빈칸·엉뚱한 그림이 보이면 [리소스팩](resource-pack.md)을 먼저 확인합니다.

**이번에 찾을 입구:** `내 섬`, `마을 이동`, `상점·거래`입니다. [메뉴 위치 안내](../guides/menu-and-navigation.md#menu-map)에서 역할을 비교할 수 있습니다.
{% endstep %}

{% step %}
### 내 섬으로 이동해요

메뉴에서 **내 섬**을 확인하고 개인 섬으로 이동합니다. 개인 섬은 기본 생산과 생활의 중심입니다.

첫 방문에는 섬 정보와 생산할 공간을 살펴보세요. 기여도·섬 퀘스트·주간 정산은 첫 활동에 익숙해진 뒤 읽어도 됩니다.
{% endstep %}

{% step %}
### 첫 활동은 하나만 골라요

아래 두 가지 중 마음에 드는 활동 하나부터 시작하세요. 기본 농사와 직접 채광은 해당 직업을 선택하지 않아도 경험할 수 있습니다.

| 해 보고 싶은 일 | 지금 할 일 |
| --- | --- |
| 작물 기르기 | [씨앗을 구하고](../economy/npc-shops.md#buy-seeds), 재배할 밭에 심은 뒤 물을 줍니다. [농사 안내](../world/farming.md#first-crop) |
| 광물 모으기 | 곡괭이를 준비해 개인 섬의 무한광산에서 직접 채광합니다. [채광 안내](../world/mining.md) |

**잠광은 직접 채광과 다른 활동**입니다. 처음부터 두 가지를 동시에 익힐 필요는 없습니다.
{% endstep %}

{% step %}
### 생산물이 생기면 보관과 판매를 확인해요

작물은 지원 품목에 맞는 농작물창고를 확인하세요. 직접 캔 광물은 잠광 산출물처럼 자동으로 광물창고에 들어가는 것이 아닙니다. [보관 장소 비교](../guides/storage-and-mail.md)

팔 물건이 준비됐다면 마을의 해당 상점이나 상점 메뉴에서 **판매 가능 여부 → 수량 → 총금액**을 확인합니다. [첫 판매 안내](../economy/npc-shops.md#first-sale)
{% endstep %}

{% endstepper %}

## 여기까지 했다면

- `/메뉴`에서 내 섬과 마을로 가는 입구를 찾을 수 있습니다.
- 농사 또는 직접 채광의 시작 방법을 알게 되었습니다.
- 생산물을 어디에 보관하고 판매할지 확인할 수 있습니다.

첫 생산물이 아직 준비되지 않았다면 기다리는 동안 직업을 비교해 보세요.
