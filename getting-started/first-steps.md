# 처음 10분

처음 접속한 뒤 아래 순서만 따라가면 MineValley의 기본 화면과 성장 방향을 익힐 수 있습니다.

{% stepper %}

{% step %}
### 화면과 리소스팩 확인

전용 글자나 메뉴가 네모, 빈칸 또는 엉뚱한 그림으로 보이면 먼저 [리소스팩 안내](resource-pack.md)를 확인하세요. 리소스팩이 적용되지 않으면 메뉴의 중요한 정보가 보이지 않을 수 있습니다.
{% endstep %}

{% step %}
### 메인 메뉴 열기

메인 메뉴 상단에서는 직업, 마을 이동, 내 섬과 마을 주민으로 이동합니다. 하단에서는 상점·거래, 개인창고와 우편함 같은 자주 쓰는 기능을 찾을 수 있습니다.

[메뉴와 이동](../guides/menu-and-navigation.md)에서 각 입구의 역할을 확인할 수 있습니다.
{% endstep %}

{% step %}
### 내 섬 확인하기

개인 섬은 기본 생산과 생활의 중심입니다. 섬으로 이동한 뒤 현재 섬 정보와 이번 주 섬 기여도·퀘스트를 살펴보세요.
{% endstep %}

{% step %}
### 농사와 채광 경험하기

작물을 기르고 광물을 모으면서 기본 생산 흐름을 익혀 보세요. 농작물은 농작물창고, 잠광 산출물은 광물창고처럼 활동에 맞는 별도 보관 공간이 있습니다.
{% endstep %}

{% step %}
### 직업 프로필 비교하기

농부·광부·가공사·기술자·방랑가의 프로필을 둘러보세요. 주 직업을 정하기 전에도 직업별 기본 활동을 체험할 수 있습니다.
{% endstep %}

{% step %}
### 첫 판매 경로 찾기

처음에는 주민 상점을 기준 판매처로 이용하고, 익숙해지면 유저거래소와 주문소를 살펴보세요. 같은 아이템도 판매 경로에 따라 조건과 목적이 다릅니다.
{% endstep %}

{% endstepper %}
