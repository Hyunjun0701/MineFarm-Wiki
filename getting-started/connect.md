# 접속 준비

MineValley는 마인크래프트 Java Edition의 전용 리소스팩을 사용하는 서버입니다. 게임을 시작하기 전에 클라이언트와 리소스팩 설정을 확인하세요.

![작은 섬과 집, 밭을 그린 MineValley 시작 안내 일러스트](../assets/images/sections/island-banner-v1.png)

## 준비할 것

| 항목 | 안내 |
| --- | --- |
| 게임 | 마인크래프트 Java Edition |
| 서버 구동 버전 | 2026년 9월 11일 확인 기준 1.21.4 |
| 리소스팩 | 서버에서 안내하는 전용 팩 다운로드 허용 |
| 접속 주소 | 운영자가 공지한 공식 주소 사용 |

다른 버전의 접속 지원이나 추가 모드 허용 여부는 운영 공지를 확인하세요. 현재 위키에는 공개 접속 주소와 공식 커뮤니티 링크가 아직 확정되지 않았습니다.

## 접속 순서

1. Java Edition을 실행하고 멀티플레이로 들어갑니다.
2. 운영자가 공지한 서버 주소로 서버를 추가합니다.
3. 해당 서버의 리소스팩 설정을 사용으로 바꿉니다.
4. 접속 후 팩 다운로드와 적용이 끝날 때까지 기다립니다.
5. `/메뉴`를 열어 글자와 그림이 정상적으로 보이는지 확인합니다.

메뉴가 네모나 빈칸으로 보이면 [리소스팩 안내](resource-pack.md)를 먼저 확인하세요.
