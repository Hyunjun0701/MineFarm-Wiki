# 리소스팩

MineFarm은 전용 리소스팩 적용이 필수인 서버입니다. 메뉴, 글자, 아이콘과 화면 연출이 리소스팩을 기준으로 만들어져 있습니다.

## 정상 적용 확인

- 메뉴 제목과 아이콘이 깨지지 않습니다.
- 전용 글자가 네모나 빈칸으로 보이지 않습니다.
- 서버가 리소스팩 적용을 완료한 뒤 정상적으로 입장됩니다.

## 적용되지 않을 때

1. 멀티플레이 서버 목록에서 MineFarm의 서버 리소스팩 설정을 확인합니다.
2. 리소스팩 다운로드를 허용합니다.
3. 다운로드가 끝나기 전에 접속을 반복하지 않습니다.
4. 계속 실패하면 사용 중인 클라이언트 버전과 오류 화면을 함께 준비해 문의합니다.

정확한 지원 버전과 별도 수동 설치 링크는 운영 정보 확인 후 공개합니다.
