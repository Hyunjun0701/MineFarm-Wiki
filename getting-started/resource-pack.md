# 리소스팩

MineValley는 전용 리소스팩 적용이 필수인 서버입니다. 메뉴의 배경과 글자, 아이콘, 커스텀 아이템과 화면 연출이 리소스팩을 기준으로 만들어져 있습니다.

## 정상 적용 확인

- 메뉴의 배경과 버튼이 서로 맞는 위치에 보입니다.
- 전용 글자가 네모나 빈칸으로 표시되지 않습니다.
- 커스텀 아이템이 종이나 엉뚱한 기본 아이템처럼 보이지 않습니다.
- 서버가 리소스팩 적용을 마친 뒤 정상적으로 입장됩니다.

## 적용되지 않을 때

1. 멀티플레이 서버 목록에서 MineValley의 서버 리소스팩 설정을 확인합니다.
2. 리소스팩 다운로드를 허용합니다.
3. 다운로드가 끝나기 전에 접속을 반복하지 않습니다.
4. 계속 실패하면 사용 중인 클라이언트 버전과 오류 화면을 함께 준비해 문의합니다.

현재 서버 구동 버전은 Java Edition 1.21.4입니다. 다른 버전의 호환 여부와 수동 설치 링크는 운영 공지를 확인하세요. [접속 준비](connect.md)에서 기본 설정을 이어서 볼 수 있습니다.
