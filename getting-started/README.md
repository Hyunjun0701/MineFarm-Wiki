# 시작하기

MineFarm은 개인 섬을 기반으로 생활 활동과 직업 성장, NPC, 거래와 공동 목표를 함께 즐기는 서버입니다.

위키를 모두 읽어야 플레이할 수 있도록 만들지 않습니다. 게임 안에서 먼저 경험하고, 궁금한 부분이 생겼을 때 이 위키를 빠르게 찾아보는 방식을 권장합니다.

## 추천 순서

1. 서버 리소스팩이 정상 적용되었는지 확인합니다.
2. 메인 메뉴를 열어 현재 이용할 수 있는 영역을 살펴봅니다.
3. 자신의 섬으로 이동해 기본 활동을 체험합니다.
4. 직업 다섯 종류의 특징을 비교합니다.
5. NPC, 퀘스트, 거래는 필요한 시점에 하나씩 익힙니다.
