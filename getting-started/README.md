# 처음 시작하기

처음에는 **접속 준비 → 첫 활동 → 첫 판매**만 따라가세요. 나머지 기능은 필요할 때 찾아보면 됩니다.

{% stepper %}
{% step %}
### 접속 준비

Java Edition과 서버 리소스팩 설정을 확인합니다. 서버 구동 버전은 **2026년 9월 11일 확인 기준 1.21.4**이며, 접속 주소는 운영자가 공지한 공식 주소를 사용하세요.

[접속 준비 따라가기](connect.md)
{% endstep %}
{% step %}
### 내 섬에서 첫 활동 시작

`/메뉴`를 열어 내 섬으로 이동하고, 농사와 직접 채광 중 해 보고 싶은 활동 하나를 고릅니다.

[처음 10분 따라가기](first-steps.md)
{% endstep %}
{% step %}
### 생산물이 생기면 판매 확인

주민 상점에서 해당 물건을 팔 수 있는지 확인합니다. 판매할 품목·수량·총금액을 확인한 뒤 거래하세요.

[첫 판매 따라가기](../economy/npc-shops.md#first-sale)
{% endstep %}
{% endstepper %}

{% hint style="info" %}
**이미 접속했나요?** 접속 준비는 건너뛰고 [처음 10분](first-steps.md)부터 시작하세요. 작물 성장과 제작에는 별도의 시간이 필요합니다.
{% endhint %}
