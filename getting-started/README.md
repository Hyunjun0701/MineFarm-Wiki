# 처음 시작하기

![섬에서 생활을 시작하는 주민들의 소개 일러스트](../assets/images/sections/island-banner-v1.png)

MineValley를 처음 시작할 때 모든 시스템을 외울 필요는 없습니다. 리소스팩을 확인하고, 메인 메뉴와 개인 섬을 익힌 뒤, 마음에 드는 활동을 하나씩 경험하면 됩니다.

## 추천 순서

1. [리소스팩](resource-pack.md)이 정상 적용됐는지 확인합니다.
2. [메뉴와 이동](../guides/menu-and-navigation.md)에서 자주 쓰는 화면의 위치를 익힙니다.
3. 개인 섬으로 이동해 기본 농사와 채광을 경험합니다.
4. [직업 다섯 종류](../jobs/README.md)를 비교합니다.
5. 생산물이 쌓이면 상점·유저거래소·주문소를 하나씩 이용합니다.
6. 섬 공동 퀘스트와 마을의 주간 목표에 참여합니다.

## 접속 정보

현재 서버는 Java Edition 1.21.4로 구동됩니다. [접속 준비](connect.md)에서 클라이언트와 리소스팩 설정을 확인하세요. 공개 주소와 공식 커뮤니티 링크는 운영 공지를 기준으로 안내합니다.
