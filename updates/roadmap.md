# 공개 로드맵

이 페이지에는 위키 제작 순서를 표시합니다. 게임 기능의 출시 날짜를 약속하는 페이지가 아닙니다.

## 문서화 완료

- 홈과 처음 10분 중심의 초보자 동선
- 직업 다섯 종류와 공통 성장 방식
- 생산 사슬, 창고, 펫과 마을 주간 활동 안내
- 작물·음식·음료·광물·제련·보석·장신구·기술 아이템 도감
- LIVE 아이템 305종과 레시피 207종의 분류·교차 검증

## 다음 보강 문서

- 광부 잠광·광맥·유물 상세 안내
- 주민별 선호 선물·세부 활동 시간과 퀘스트 조건의 추가 검증
- 공개 가능한 가격·확률·보상 수치의 지속 갱신
- 실제 플레이 검수에서 발견한 문서 차이 반영

## 시각 구성 완료

- 홈과 월드·경제·섬·직업 섹션의 대표 이미지
- 301종 아이템 이미지 도감과 상세 제작표의 실제 아이콘

- 위키 엠블럼과 PC·모바일용 전체 문서 미리보기

- 실제 GUI 스크린샷과 클릭 위치 설명
