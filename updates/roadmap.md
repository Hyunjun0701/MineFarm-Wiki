# 공개 로드맵

이 페이지에는 공개해도 되는 예정 항목만 표시합니다. 날짜가 확정되지 않은 항목은 순서를 약속하지 않습니다.

## 진행 중

- MineFarm 플레이어 위키 기본 구조와 검색 동선
- PC·모바일 공통 문서 형식
- 아이템 도감 구조화 데이터와 자동 생성 기반

## 다음 공개 후보

- 서버 접속·클라이언트·공식 링크 안내
- 직업별 실제 화면과 단계별 가이드
- 아이템 도감 첫 검증 데이터
- 주요 메뉴와 명령어 안내
- 자주 묻는 질문

## 이후 확장

- 아이템 획득처·사용처 연결
- 직업별 관련 아이템 필터
- 업데이트와 영향받는 문서 자동 연결
- 검색 실패어를 반영한 용어·동의어 보완

게임 기능의 개발 로드맵은 Moon이 공개를 승인한 항목만 별도로 추가합니다.
