# 2026-09-11 — 위키 2차 개편 시작

MineValley의 개발 범위가 크게 넓어진 현재 상태에 맞춰 플레이어 위키의 두 번째 구성을 시작했습니다.

## 이번에 바뀐 것

- 공개 이름을 MineValley 기준으로 정리했습니다.
- 오래된 `상인` 문서를 현재 표시명인 `방랑가`로 교체했습니다.
- 홈과 처음 10분을 실제 플레이 순서에 맞춰 다시 작성했습니다.
- 메뉴와 이동, 창고와 우편함, 펫 안내를 추가했습니다.
- 생산과 수요가 연결되는 전체 흐름을 새로 설명했습니다.
- 다섯 직업의 소개와 공통 성장 방식을 확장했습니다.
- 섬 퀘스트, 주간 테마와 정산의 차이를 나누어 설명했습니다.
- 유저거래소에서 현재 제공하지 않는 검색·태그 안내를 제거했습니다.
- 농사, 광산과 잠광, 가공, 기술 설비의 실제 이용 흐름을 추가했습니다.
- 플레이어 명령어와 문제 해결 중심의 자주 묻는 질문을 정리했습니다.
- LIVE 서버에 등록·배치된 주민 45명과 별도 상점 NPC 5명을 기준으로 주민 안내를 다시 작성했습니다.
- LIVE 운영본의 작물 22종, 씨앗 44종, 가공 레시피 135종, 조립 레시피 72종, 운영 장신구 36종과 유물 10종을 문서에 반영했습니다.
- 아이템 305종의 분류와 레시피 207종의 제작 체계를 정리하고, 작물 22종의 성장·품질·가공 사용처 도감을 추가했습니다.
- 요리 25종과 바리스타 음료 29종을 현재 해금 조건과 제작 시간 기준으로 정리했습니다.
- 압축 광물 8종, 합금·판재 8종, 하위 보석 8종, 정령석 6종과 탄생석 12종의 현재 제작법을 추가했습니다.
- 장신구 36종의 제작 재료, 고유 효과 30종, 고유 효과 미연결 6종과 공명 규칙을 추가했습니다.
- 기술 중간재 27종, 기술대·기반 설비 7종과 완제품 41종의 제작법·현재 기능을 전수 정리했습니다.
- 세계의 근원 5종과 월드코어 흐름을 추가하고, LIVE에서 아직 열리지 않은 제단·방랑가 획득 경로를 준비 중으로 구분했습니다.

## 전체 문서·디자인 구성

전체 100개 문서로 첫 접속부터 직업·생활·경제·제작 도감·주민 안내까지 이어지는 구성을 마련했습니다.

- 접속과 설치, 주민 상점과 개인 주문 안내를 추가했습니다.
- 주민 45명의 개별 소개를 작성하고, 제공된 실제 초상 38종을 연결했습니다.
- 플레이어용 아이템 301종의 이미지 도감과 상세 제작표에 실제 아이콘을 넣었습니다.
- 다섯 직업의 성장 안내를 현재 고정 성장표에 맞추고, 액티브 기술의 기본 조작을 추가했습니다.
- 거래소 기본 제한·수수료와 섬의 주간 정산 시각을 현재 설정에 맞췄습니다.
- 월드·경제·섬 배너와 위키 엠블럼을 제작하고, 전체 문서를 검색할 수 있는 PC·모바일 디자인 미리보기를 만들었습니다.

이번 버전은 전체 문서와 이미지, 안내 박스·탭·단계 안내를 포함하는 2차 개편본입니다. 거래 문서의 명칭은 주민 상점·유저거래소·주문소로 통일했고, 방랑가 전용 개인 주문은 주문소 하단에서 이어집니다. 별도 디자인 미리보기와 실제 GitBook의 화면 구성은 다를 수 있습니다.

공식 접속 주소·공식 커뮤니티 링크와 신규 실제 플레이 스크린샷은 확인한 뒤 추가합니다. 공개 화면에서 발견한 표시 차이와 게임 내 최종 검수 결과도 계속 반영합니다.
