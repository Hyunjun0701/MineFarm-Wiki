# 명령어 모음

MineValley의 주요 기능은 메뉴와 NPC를 통해 이용할 수 있으며, 자주 쓰는 기능은 명령어로도 열 수 있습니다. 아래에는 플레이어가 사용하는 명령어만 모았습니다.

## 자주 쓰는 명령어

{% hint style="info" %}
**명령어 읽는 법**

`<닉네임>`·`<금액>`에는 실제 값을 넣고 괄호는 지웁니다. `[가격]`처럼 대괄호로 표시한 값은 선택 입력입니다. 명령어별 게임 도움말도 함께 확인하세요.
{% endhint %}

{% tab title="기본과 경제" %}
## 기본과 경제

| 명령어 | 기능 |
| --- | --- |
| `/메뉴` | 메인 메뉴 열기 |
| `/스폰` | 서버 공용 스폰으로 이동 |
| `/돈` | 현재 보유 금액과 송금 안내 확인 |
| `/돈 보내기 <닉네임> <금액>` | 다른 플레이어에게 금액 보내기 |
| `/송금 <닉네임> <금액>` | 다른 플레이어에게 금액 보내기 |
| `/캐시` | 캐시 관련 화면 또는 정보 확인 |
| `/수표 발행 <금액>` | 보유 금액으로 수표 발행 |
| `/수표 환전` | 손에 든 수표 환전 |
| `/수표 정보` | 손에 든 수표 정보 확인 |

{% hint style="warning" %}
**돈이 이동하는 명령어입니다**

금액을 보내거나 수표를 발행하기 전에 **닉네임과 금액**을 한 번 더 확인하세요.
{% endhint %}

{% tab title="직업과 생산" %}
## 직업과 생산

| 명령어 | 기능 |
| --- | --- |
| `/직업` | 직업 상태와 도움말 확인 |
| `/직업 상태` | 현재 직업과 성장 상태 확인 |
| `/직업 전직 <직업>` | 선택한 직업으로 전직 시도 |
| `/가공도감` | 가공 품목과 해금 상태 확인 |
| `/세공` | 세공 화면 열기 |
| `/농작물창고` | 농작물 전용 창고 열기 |
| `/라인` | 바라보는 기술 작업대의 라인 확인 |
| `/설계도` | 기술 설계도 화면 열기 |
| `/기술자 제작 자동줍기 <20·50·100>` | 재료를 사용해 자동줍기 이용권 제작 |
| `/기술자 제작 자동심기 <20·50·100>` | 재료를 사용해 자동심기 이용권 제작 |
| `/자동줍기` | 자동줍기 상태 확인·변경 |
| `/자동심기` | 자동심기 상태 확인·변경 |
| `/야영지` | 방랑가 야영지 기능 열기 |
| `/방랑가` | 방랑가 의뢰 도움말 확인 |
| `/세계근원` | 세계의 근원 상태와 도움말 확인 |

{% hint style="info" %}
**명령어가 있어도 사용 조건이 있습니다**

자동줍기와 자동심기는 기능을 사용할 수 있는 조건이나 이용권이 필요할 수 있습니다.
{% endhint %}
{% endtab %}

{% tab title="거래와 주문" %}
## 거래와 주문

| 명령어 | 기능 |
| --- | --- |
| `/상점` | 기본 서버 상점 열기 |
| `/광물상점` | 광물 상점 열기 |
| `/교환` | 마을 교환소 열기 |
| `/시장` | 현재 열린 시장 상황 확인 |
| `/유저거래` | 유저거래소 화면 열기 |
| `/유저거래 판매 [가격] [수량]` | 손에 든 아이템 판매 등록 |
| `/유저거래 내등록` | 내가 등록한 판매 목록 확인 |
| `/requestorder` | 주문소 화면 열기 |
| `/개인주문 <닉네임>` | 주문소의 방랑가 전용 개인 주문에서 납품 상대 지정 |
| `/시장거래` | 플레이어 간 직접 거래 도움말 확인 |

판매 등록과 주문은 서로 다른 거래 방식입니다. 차이는 [경제와 거래](../economy/README.md)에서 확인하세요.
{% endtab %}

## 섬·마을과 편의 기능
