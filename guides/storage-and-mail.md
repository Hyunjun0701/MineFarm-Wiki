# 창고와 우편함

아이템을 보관하거나 선물을 찾을 때는 아래 표에서 알맞은 창고를 골라 보세요. 보관할 수 있는 물건과 꺼내는 방법이 창고마다 다릅니다.

## 보관 공간 비교

| 공간 | 주된 용도 | 들어오는 예시 |
| --- | --- | --- |
| 개인창고 | 일반 아이템 보관 | 플레이어가 직접 넣은 아이템 |
| 우편함 | 선물과 운영 지급 수령 | 다른 플레이어의 선물, 운영 지급 |
| 농작물창고 | 농사 생산물 관리 | 지원되는 작물 수확물 |
| 광물창고 | 잠광 산출물 관리 | 온라인 잠광과 관련 채굴 산출물 |
| 펫 가방 | 자동줍기 펫의 수집 공간 | 펫이 대신 수집한 아이템 |

## 개인창고

개인창고는 일반적인 보관 공간입니다. 잠긴 공간의 해금 조건과 비용은 현재 게임 화면에 표시되는 값을 확인하세요.

## 우편함과 선물

손에 든 아이템은 `/선물 <플레이어> [수량]`으로 다른 플레이어의 우편함에 보낼 수 있습니다. 보내기 전 대상, 아이템과 수량을 다시 확인하세요.

우편함에 도착한 아이템은 직접 확인하고 수령합니다. 인벤토리 공간이 충분한지 확인한 뒤 수령하는 것이 안전합니다.

## 농작물창고와 광물창고 <a href="#직업-전용-창고" id="직업-전용-창고"></a>

농작물창고와 광물창고는 생산 활동에 맞춘 별도 공간입니다. 일반 개인창고와 자동으로 합쳐지지 않습니다.

- 농작물창고는 모든 플레이어가 사용할 수 있는 농사 기반 시설입니다.
- 온라인 잠광을 끝내면 모은 광물이 광물창고에 들어갑니다.
