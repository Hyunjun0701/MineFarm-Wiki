# 주간 테마와 정산

마을 활동은 한 주마다 새로 시작합니다. 모든 섬이 같은 주간 테마에 참여하며, 내 섬의 퀘스트와 기여도는 섬 화면에서 확인할 수 있습니다.

## 한 주의 일정 <a href="#한-주의-흐름" id="한-주의-흐름"></a>

2026년 9월 11일 서버 설정과 주간 일정 기준입니다. 모든 시각은 한국 실제 시각입니다.

| 시점 | 진행 내용 |
| --- | --- |
| 월요일 00:00 | 지난 주차 마감 |
| 월요일 00:00~06:00 | 새 주차 준비 시간, 납품 불가 |
| 월요일 06:00 | 새 주차 시작, 이번 주 테마와 활동 확인 |
| 주차가 열린 날의 06:00 | 오늘의 섬 퀘스트 생성 |
| 주중 | 섬 퀘스트·공공 납품, 마을 단계와 보상 진행 |
| 마감 전 | 순위 비공개 구간과 최종 정산 준비 |

{% hint style="warning" %}
**월요일 00:00부터 06:00까지는 납품할 수 없습니다.** 게임 속 낮·밤과 관계없이 한국 실제 시각을 기준으로 하니 마감 전에 납품을 마치세요.
{% endhint %}

마감 후에는 섬 화면에서 확정된 순위와 보상을 확인하세요.

## 주간 테마

테마에 따라 마을이 필요로 하는 물품의 종류가 달라집니다. 농작물·음식·광물·기술 소재 중 이번 주에 어떤 물품을 찾는지 살펴보세요. 테마 자체가 요구 수량이나 보상을 바꾸지는 않습니다.

한 번 정해진 테마는 같은 주 동안 유지됩니다. 현재 테마와 설명은 섬 퀘스트 화면에서 확인할 수 있습니다.

## 마을 단계

여러 섬이 공공 납품에 참여하면 마을 단계가 올라갑니다. 단계가 바뀌면 적용되는 효과와 내 섬이 받을 수 있는 보상을 화면에서 확인하세요.

## 랭킹과 정산

주간 마감이 가까워지면 현재 순위가 보이지 않는 시간이 있습니다. 순위가 표시되지 않아도 마감 전까지 가능한 활동에 참여할 수 있습니다.

정산이 끝나면 최종 섬 순위와 보상을 확인하세요. 섬 공동 보상은 섬 보상함에 들어갈 수 있으니 개인 우편함만 확인하고 놓치지 않도록 주의하세요.

## 새로 만든 섬

주중에 새로 만든 섬은 참여할 수 있는 시점과 활동이 다를 수 있습니다. 섬 화면에서 참여 시작 시점과 가능한 활동을 확인하세요.

납품할 준비가 됐다면 [섬 기여도와 섬 퀘스트](contribution-and-quests.md)에서 물품 확인과 납품 순서를 살펴보세요.
