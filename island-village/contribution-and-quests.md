# 섬 기여도와 섬 퀘스트

섬 기여도와 섬 퀘스트는 같은 섬에 속한 플레이어가 공동 목표에 참여하는 활동입니다.

## 기본 흐름

1. 메인 메뉴에서 내 섬으로 이동합니다.
2. 섬 기여도 화면을 엽니다.
3. 현재 섬 퀘스트 목록과 진행 상황을 확인합니다.
4. 납품할 퀘스트와 수량을 선택합니다.
5. 최종 확인 후 실제 아이템을 납품합니다.

## 알아둘 점

- 진행과 보상은 개인이 아니라 섬을 기준으로 다뤄지는 항목이 있습니다.
- 이미 생성된 퀘스트의 조건은 도중에 임의로 바뀌지 않습니다.
- 주중에 새로 만들어진 섬에는 별도의 참여 시작 규칙이 적용됩니다.
- 상세 요구량과 보상은 현재 게임 화면의 값을 확인하세요.

섬 기여도, 기여 점수, 마을 기여 점수는 서로 다른 의미를 가질 수 있으므로 같은 수치로 생각하지 않습니다.
