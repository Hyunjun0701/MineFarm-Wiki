# MineValley에 오신 것을 환영해요

![작은 섬에서 농사와 공방 생활을 함께하는 MineValley 소개 일러스트](assets/images/sections/island-banner-v1.png)

MineValley는 개인 섬에서 시작해 농사와 채광으로 재료를 모으고, 가공과 기술 제작으로 가치를 높여 마을의 수요와 다른 플레이어의 주문에 연결하는 생활 성장 서버입니다.

오늘은 밭을 가꾸고, 내일은 공방을 열어 보세요. 주민을 만나고 이웃과 물건을 나누며 나만의 생활을 만들어 갈 수 있습니다.

처음 시작하는 분은 [접속 준비](getting-started/connect.md)와 [처음 10분](getting-started/first-steps.md)부터, 필요한 아이템이 있는 분은 [그림 도감](atlas/visual-index.md)부터 살펴보세요.

## MineValley의 핵심 흐름

| 모으고 | 만들고 | 함께 성장해요 |
| --- | --- | --- |
| [농사와 채광](world/README.md)으로 재료를 모아요 | [가공](world/processing.md)과 [기술 제작](world/technology.md)으로 가치를 더해요 | [거래](economy/README.md)와 [섬 공동 활동](island-village/README.md)에 연결해요 |

한 가지 길만 따라갈 필요는 없습니다. 기본 활동은 누구나 경험할 수 있고, 주 직업은 선택한 분야의 성장과 전문 기능을 더 깊게 열어 줍니다.

## 마을과 도감을 둘러보세요

다섯 직업, 주민 45명과 작물·가공·기술 계열 도감이 여러분을 기다립니다. [주민 이름과 얼굴](residents/README.md)을 알아보고, [301종 그림 도감](atlas/visual-index.md)에서 다음에 만들 아이템을 찾아보세요.
