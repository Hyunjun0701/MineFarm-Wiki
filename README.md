# 홈

> 위키는 현재 서버에서 실제로 이용할 수 있는 기능을 설명합니다. 검토 중이거나 아직 공개하지 않은 내용은 일반 가이드와 섞지 않습니다.

## 현재 안내하는 핵심 영역

* 개인 섬과 섬 공동 활동
* 농부·광부·가공사·상인·기술자 직업
* 서버 화폐, 상점, 유저 거래와 공개 주문
* NPC 관계와 퀘스트
* 섬 기여도, 섬 퀘스트와 주간 활동

세부 수치나 조건은 실제 동작 확인을 마친 항목부터 순차적으로 공개합니다.
