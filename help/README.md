- 직업을 고르기 어렵다면 [직업과 성장](../jobs/README.md)

## 문의할 때 준비할 정보

- 마인크래프트 닉네임
- 문제가 발생한 날짜와 대략적인 시각
- 이용하던 메뉴, NPC 또는 기능
- 화면에 표시된 정확한 문구
- 가능하면 문제 화면과 직전 행동

서버 주소, 공식 커뮤니티 링크와 세부 문의 채널은 운영 정보 승인 후 추가합니다.
