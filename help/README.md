## 문의할 때 준비할 정보

- 마인크래프트 닉네임
- 문제가 발생한 대략적인 시각
- 이용하던 메뉴 또는 기능
- 화면에 표시된 메시지
- 가능한 경우 문제 화면

서버 주소, 공식 디스코드 링크와 세부 신고 절차는 Moon의 운영 정보 승인 후 추가합니다.

## 위키 정보가 실제 게임과 다를 때

위키 문구를 새로운 규칙으로 해석하지 마세요. 실제 게임 동작과 위키가 다르면 변경을 확정하지 않고 검토 항목으로 접수합니다.
