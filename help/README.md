# 도움말

궁금한 기능의 안내를 먼저 찾아보세요. 문제가 계속되면 아래 정보를 함께 준비해 주세요.

## 먼저 확인하세요

- 화면이나 커스텀 아이템이 깨지면 [리소스팩](../getting-started/resource-pack.md)
- 처음 무엇을 해야 할지 모르겠다면 [처음 10분](../getting-started/first-steps.md)
- 메뉴 위치가 헷갈리면 [메뉴와 이동](../guides/menu-and-navigation.md)
- 직업을 고르기 어렵다면 [직업과 성장](../jobs/README.md)
- 거래 방식이 헷갈리면 [경제와 거래](../economy/README.md)
- 섬 퀘스트 납품이 궁금하면 [섬 기여도와 섬 퀘스트](../island-village/contribution-and-quests.md)
- 펫 기능이 작동하지 않으면 [펫](../guides/pets.md)
- 명령어를 찾고 있다면 [명령어 모음](../guides/commands.md)
- 기능이 예상대로 작동하지 않으면 [자주 묻는 질문](../guides/faq.md)

## 문의할 때 준비할 정보

- 마인크래프트 닉네임
- 문제가 발생한 날짜와 대략적인 시각
- 이용하던 메뉴, NPC 또는 기능
- 화면에 표시된 정확한 문구
- 가능하면 문제 화면과 직전 행동

접속 주소는 `minevalley.kr`입니다. 게임 버전과 리소스팩 설정은 [접속 준비](../getting-started/connect.md)에서 확인하세요. 공식 커뮤니티 링크와 세부 문의 채널은 확정 후 안내합니다.

## 위키 정보가 실제 게임과 다를 때

게임 화면과 위키의 설명이 다르면 해당 화면과 문서 주소를 함께 알려 주세요. 이용 조건은 게임에 표시된 안내를 먼저 확인해 주세요.
