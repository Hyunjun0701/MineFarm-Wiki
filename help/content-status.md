# 콘텐츠 표시 기준

위키에서 기능의 현재 상태를 확인할 때 쓰는 표시입니다.

| 표시 | 의미 |
|---|---|
| 현재 이용 가능 | 지금 게임에서 이용할 수 있는 기능 |
| 확인 중 | 아직 정확한 안내를 확인하고 있는 내용 |
| 공개 예정 | 앞으로 추가할 예정으로 안내된 내용 |
| 종료·변경 | 더 이상 같은 방식으로 이용할 수 없음 |

## 예정 내용을 읽을 때

`공개 예정`인 기능은 아직 이용할 수 없습니다. 별도 날짜가 없다면 추가 시기도 정해지지 않은 상태입니다.

위키에 보강할 안내는 [공개 로드맵](../updates/roadmap.md), 달라진 내용은 [업데이트](../updates/README.md)에서 확인하세요.
