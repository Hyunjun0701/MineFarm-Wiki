# 콘텐츠 표시 기준

MineFarm 위키는 현재 기능과 예정 내용을 다음처럼 구분합니다.

| 표시 | 의미 |
|---|---|
| 현재 이용 가능 | 실제 서버 동작과 공개 문구 확인 완료 |
| 확인 중 | 사실 또는 표현을 검토 중이며 확정 안내가 아님 |
| 공개 예정 | Moon이 공개를 승인한 향후 항목 |
| 종료·변경 | 더 이상 같은 방식으로 이용할 수 없음 |

## 예정 기능 공개 원칙

- 공개했을 때 플레이어 경험에 도움이 되는 항목만 선택합니다.
- 일정이 확정되지 않았다면 날짜를 약속하지 않습니다.
- 내부 구현 방식과 개발 문서를 노출하지 않습니다.
- 현재 기능 설명 안에 예정 기능을 섞지 않습니다.
- 방향이 바뀌면 로드맵을 수정하고 변경 이력을 남깁니다.
