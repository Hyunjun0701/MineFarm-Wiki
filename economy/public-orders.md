# 공개 주문

공개 주문은 구매자가 원하는 아이템, 수량과 보상을 제시하고 다른 플레이어가 조건에 맞춰 납품하는 거래 방식입니다.

## 주문을 만들 때

- 요청 아이템과 수량을 선택합니다.
- 지급할 총보상을 확인합니다.
- 주문 생성 전에 보상이 먼저 확보됩니다.
- 본인이 만든 미완료 주문은 정해진 방식으로 취소할 수 있습니다.

## 주문에 납품할 때

- 공개 목록에서 주문 조건을 확인합니다.
- 요청된 수량 전체를 준비합니다.
- 최종 확인 후 납품합니다.
- 완료된 주문의 지급 상태를 확인합니다.

공개 주문은 일반 유저 거래와 목적이 다릅니다. 유저 거래가 판매 목록이라면, 공개 주문은 구매자가 먼저 만든 확정 수요입니다.
