# 주문소

주문소에서는 필요한 아이템과 수량, 지급할 보상을 정해 주문할 수 있습니다. 물건을 가진 플레이어는 주문 조건을 확인한 뒤 납품합니다. `/requestorder`로 주문소를 여세요.

## 주문 만들기

필요한 물건을 구하는 쪽이라면 주문을 만드세요.

1. 요청할 아이템을 선택합니다.
2. 필요한 수량과 지급할 총보상을 입력합니다.
3. 주문 생성 전 최종 내용을 확인합니다.
4. 주문을 등록합니다. 지급할 보상은 등록할 때 미리 맡깁니다.

내가 만든 미완료 주문은 주문 화면에서 취소할 수 있습니다. 취소한 뒤에는 주문 상태와 보상 반환 여부를 확인하세요.

## 주문에 납품하기

다른 플레이어가 찾는 물건을 가지고 있다면 주문에 납품하세요.

1. 공개 목록에서 주문 조건을 확인합니다.
2. 요청된 아이템과 수량을 준비합니다.
3. 상세 화면에서 납품 가능 여부를 확인합니다.
4. 최종 확인 후 납품합니다.
5. 완료 상태와 보상 수령을 확인합니다.

{% hint style="warning" %}
**일반 주문은 전량을 한 번에 납품합니다**

부분 납품이나 여러 명이 나누어 채우는 방식이 아닙니다. 요청된 품목과 수량을 모두 준비한 뒤 납품하세요.
{% endhint %}

## 현재 주문 한도

2026년 9월 11일 서버 설정 기준, 미완료 주문은 플레이어당 3건까지 만들 수 있습니다. 납품이 진행 중인 주문도 한도에 포함됩니다.

일반 주문은 자동으로 만료되지 않습니다. 더 이상 필요하지 않은 주문은 직접 취소하고 보상 반환 여부를 확인하세요.

## 유저거래소와의 차이

[유저거래소](player-market.md)에서는 팔 물건과 가격을 정해 등록합니다. 주문소에서는 필요한 물건과 지급할 보상을 정해 요청합니다. 가진 물건을 팔고 싶다면 주문 목록에서 찾는 사람이 있는지 살펴보거나 유저거래소에 등록하세요.
