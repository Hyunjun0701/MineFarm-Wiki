# 주문소

주문소에서는 구매자가 원하는 아이템, 수량과 보상을 먼저 제시하고 다른 플레이어가 조건에 맞춰 납품합니다. 먼저 일반 주문의 이용 방법을 확인하고, 방랑가는 이 페이지 아래의 [전용 개인 주문](#wanderer-private-orders)으로 이어서 확인하세요.

## 주문 만들기

`/requestorder`로 주문소 화면을 열 수 있습니다.

1. 요청할 아이템을 선택합니다.
2. 필요한 수량과 지급할 총보상을 입력합니다.
3. 주문 생성 전 최종 내용을 확인합니다.
4. 주문을 만들면 약속한 보상이 먼저 확보됩니다.

본인이 만든 미완료 주문은 정해진 방식으로 취소할 수 있습니다. 취소 결과와 반환 상태를 주문 화면에서 확인하세요.

## 주문에 납품하기

1. 공개 목록에서 주문 조건을 확인합니다.
2. 요청된 아이템과 수량을 준비합니다.
3. 상세 화면에서 납품 가능 여부를 확인합니다.
4. 최종 확인 후 납품합니다.
5. 완료 상태와 보상 수령을 확인합니다.

{% hint style="warning" %}
**일반 주문은 전량을 한 번에 납품합니다**

부분 납품이나 여러 명이 나누어 채우는 방식이 아닙니다. 요청된 품목과 수량을 모두 준비한 뒤 납품하세요.
{% endhint %}

## 현재 주문 한도

2026년 9월 11일 서버 설정의 미완료 주문 한도는 플레이어당 3건입니다. 진행 중이거나 납품 처리를 위해 확보된 주문도 한도에 포함됩니다. 일반 주문에는 자동 만료가 없으므로 더 이상 필요하지 않은 미완료 주문은 주문 화면에서 취소 결과를 확인하세요.

## 유저거래소와의 차이

유저거래소는 판매자가 먼저 물건을 올리고, 주문소는 구매자가 먼저 수요와 보상을 올립니다. 팔 물건이 이미 있다면 유저거래소가, 꼭 필요한 물건을 구하고 싶다면 주문소가 더 잘 맞습니다.
