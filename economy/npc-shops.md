# 주민 상점

주민 상점에서 씨앗과 생활 물품을 사고, 상점에서 받는 생산물을 팔 수 있습니다. 거래할 품목과 가격은 상점 화면에서 확인하세요.

![농산물과 음식, 생활 물품을 진열한 시장 소개 일러스트](../assets/images/sections/economy-banner-v1.png)

## 첫 씨앗 구입하기 <a href="#buy-seeds" id="buy-seeds"></a>

농사를 시작하려면 `/메뉴`에서 상점·거래 입구를 확인하거나 마을의 상점 NPC를 찾아가세요. 일반 작물의 씨앗은 **작물 상점**, 허브 재배 품목은 **허브 상점**에서 확인합니다.

구입할 씨앗을 골랐다면 구매 수량과 총금액을 확인하세요. 재배 조건은 [작물 도감](../atlas/crops.md), 심고 물을 주는 방법은 [농사 안내](../world/farming.md)에서 확인할 수 있습니다. 수확한 뒤에는 아래의 [첫 판매 안내](#first-sale)를 따라가세요.

## 첫 판매 따라가기 <a href="#first-sale" id="first-sale"></a>

팔 물건이 생겼다면 먼저 주민 상점에서 취급하는 품목인지 확인하세요. 아직 생산물이 없다면 [처음 10분](../getting-started/first-steps.md)에서 첫 활동을 시작합니다.

{% stepper %}
{% step %}
### 해당 상점 열기

`/메뉴`의 상점·거래 입구를 확인하거나 마을의 상점 NPC를 찾습니다. 작물은 작물 상점, 광물은 광물 상점처럼 팔 물건에 맞는 상점을 고르세요.
{% endstep %}
{% step %}
### 판매 가능 여부 확인

상점 화면에서 품목과 **구매·판매 구분**을 확인합니다. 목록에 없거나 판매를 받지 않는 물건은 [유저거래소](player-market.md)나 [주문소](public-orders.md)를 살펴보세요.
{% endstep %}
{% step %}
### 수량과 총금액 확인 후 거래

팔 품목과 수량, 최종 금액을 확인한 뒤 진행합니다. 판매하려는 상황에서 구매를 선택하지 않았는지 다시 확인하세요.
{% endstep %}
{% step %}
### 아이템과 잔액 확인

거래 뒤 아이템 수량과 잔액을 확인합니다. 결과가 보이지 않으면 같은 거래를 반복하지 마세요.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
**모든 물건을 상점에 팔 수 있는 것은 아닙니다.** 아래 표에서 상점을 고른 뒤, 게임 화면에서 해당 품목을 사고팔 수 있는지 확인하세요.
{% endhint %}

## 어떤 상점을 찾을까요?

2026년 9월 11일 확인한 전용 상점 NPC는 아래 다섯 종류입니다. [마을 주민](../residents/README.md) 45명과는 별도로 만날 수 있습니다.

| 상점 | 확인할 품목 |
| --- | --- |
| 작물 상점 | 작물과 씨앗 계열 |
| 허브 상점 | 허브와 관련 재배 품목 |
| 광물 상점 | 채광으로 얻은 광물 계열 |
| 요리 상점 | 음식·가공 식품 계열 |
| 음료 상점 | 커피·허브 음료 계열 |
