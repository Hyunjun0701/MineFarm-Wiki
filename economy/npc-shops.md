# 주민 상점

주민 상점에서는 서버가 정한 품목과 현재 가격을 확인하고 거래합니다. 주민의 대화·관계 기능과 상점 거래는 서로 구분됩니다.

![농산물과 음식, 생활 물품을 진열한 시장 소개 일러스트](../assets/images/sections/economy-banner-v1.png)

## 첫 판매 따라가기 <a href="#first-sale" id="first-sale"></a>

팔 물건이 생겼다면 먼저 주민 상점에서 취급하는 품목인지 확인하세요. 아직 생산물이 없다면 [처음 10분](../getting-started/first-steps.md)에서 첫 활동을 시작합니다.

{% stepper %}
{% step %}
### 해당 상점 열기

`/메뉴`의 상점·거래 입구를 확인하거나 마을의 해당 상점 NPC를 찾습니다. 작물은 작물 상점, 광물은 광물 상점처럼 물건에 맞는 상점을 확인하세요.
{% endstep %}
{% step %}
### 판매 가능 여부 확인

상점 화면에서 품목과 **구매·판매 구분**을 확인합니다. 목록에 없거나 판매할 수 없는 물건은 여기서 거래하지 않고 다른 경로를 살펴보세요.
{% endstep %}
{% step %}
### 수량과 총금액 확인 후 거래

팔 품목과 수량, 최종 금액을 확인한 뒤 진행합니다. 판매하려는 상황에서 구매를 선택하지 않았는지 다시 확인하세요.
{% endstep %}
{% step %}
### 아이템과 잔액 확인

거래 뒤 아이템 수량과 잔액에 결과가 반영됐는지 확인합니다. 변화가 보이지 않으면 같은 거래를 반복하기 전에 현재 상태를 확인하세요.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
**모든 물건을 상점에 팔 수 있는 것은 아닙니다.** 아래 분류는 확인할 상점을 고르는 안내입니다. 실제 거래는 현재 화면의 품목·구매 및 판매 가능 여부를 기준으로 합니다.
{% endhint %}

## 어떤 상점을 찾을까요?

2026년 9월 11일 서버에 등록된 전용 상점 NPC는 아래 다섯 종류입니다. 이들은 주민 45명과 별도로 집계합니다.

| 상점 | 확인할 품목 |
| --- | --- |
| 작물 상점 | 작물과 씨앗 계열 |
| 허브 상점 | 허브와 관련 재배 품목 |
| 광물 상점 | 채광으로 얻은 광물 계열 |
| 요리 상점 | 음식·가공 식품 계열 |
| 음료 상점 | 커피·허브 음료 계열 |
