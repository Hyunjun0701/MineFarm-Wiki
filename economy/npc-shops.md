# 주민 상점

주민 상점에서는 서버가 정한 품목과 현재 가격을 확인하고 거래합니다. 주민의 대화·관계 기능과 상점 거래는 서로 구분됩니다.

![농산물과 음식, 생활 물품을 진열한 시장 소개 일러스트](../assets/images/sections/economy-banner-v1.png)

## 상점 종류

2026년 9월 11일 서버에 등록된 전용 상점 NPC는 아래 다섯 종류입니다. 이들은 주민 45명과 별도로 집계합니다.

| 상점 | 확인할 품목 |
| --- | --- |
| 작물 상점 | 작물과 씨앗 계열 |
| 허브 상점 | 허브와 관련 재배 품목 |
| 광물 상점 | 채광으로 얻은 광물 계열 |
| 요리 상점 | 음식·가공 식품 계열 |
| 음료 상점 | 커피·허브 음료 계열 |

위 분류의 모든 아이템을 항상 사고팔 수 있다는 뜻은 아닙니다. 현재 상점 화면에 올라온 품목과 구매·판매 가능 여부를 확인하세요.

## 거래 순서

1. 마을의 해당 상점 NPC 또는 상점 메뉴를 엽니다.
2. 원하는 품목의 구매·판매 구분과 수량을 확인합니다.
3. 최종 금액과 거래 가능한 수량을 확인하고 진행합니다.
4. 아이템과 잔액이 반영됐는지 확인합니다.

현재 판매할 수 없는 물건은 [유저거래소](player-market.md)의 등록 가능 여부나 [주문소](public-orders.md)의 수요를 살펴보세요.
