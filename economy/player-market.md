# 유저거래소

유저거래소에서는 판매할 아이템의 수량과 가격을 직접 정할 수 있습니다. `/유저거래`로 거래소를 열고, 올린 물건은 `/유저거래 내등록`에서 확인하세요.

## 판매 등록

판매할 아이템을 준비한 뒤 등록 화면에서 수량, 가격과 예상 수령액을 확인하세요.

{% stepper %}

{% step %}
### 아이템 준비

판매할 아이템을 준비하고 등록 화면의 안내를 따릅니다.
{% endstep %}

{% step %}
### 가격과 수량 입력

가격과 수량을 입력합니다.
{% endstep %}

{% step %}
### 등록 내용 확인

등록 전 아이템, 수량과 총가격을 다시 확인합니다.
{% endstep %}

{% step %}
### 내 등록 확인

등록 뒤 `내 등록` 화면에서 정상적으로 올라갔는지 확인합니다.
{% endstep %}

{% endstepper %}

등록한 아이템은 판매 중에 인벤토리에서 사용할 수 없습니다. 되찾으려면 `내 등록`에서 취소와 회수 가능 여부를 확인하세요.

## 목록 살펴보기

카테고리와 정렬로 원하는 물건을 찾으세요. 구매 전에는 가격뿐 아니라 수량, 아이템 상태와 판매 조건도 함께 확인합니다.

## 판매 완료·취소·만료

- 판매가 끝났다면 `내 등록`에서 대금 수령 상태를 확인하세요.
- 판매를 중단하려면 `내 등록`에서 취소하고 남은 아이템을 회수하세요.
- 만료된 물건은 `내 등록`에서 상태와 회수 가능 여부를 확인하세요. 자동으로 우편이 올 때까지 기다리지 마세요.

정확한 등록 한도와 판매 수수료는 등록 화면에 표시되는 현재 값을 기준으로 합니다.

## 기본 등록 한도와 수수료 <a href="#현재-기본-운영값" id="현재-기본-운영값"></a>

2026년 9월 11일 서버 설정 기준입니다. 직업 효과나 혜택에 따라 내 등록 화면에 표시되는 값은 다를 수 있습니다.

| 항목 | 기본값 |
| --- | --- |
| 동시 등록 한도 | 7건 |
| 등록 유효 기간 | 7일 |
| 판매 성공 수수료 | 판매 금액의 5% |

{% hint style="warning" %}
**만료 물품도 등록 한도를 차지합니다**

새 등록이 막히면 `내 등록`에서 **만료 물품부터 회수**하세요. 수수료 조건은 등록할 때 정해지므로 등록 확인 화면의 예상 수령액을 확인하세요.
{% endhint %}

원하는 물건을 찾지 못했다면 [주문소](public-orders.md)에서 품목과 보상을 정해 주문할 수 있습니다. 거래 방법을 비교하려면 [경제와 거래](README.md)를 확인하세요.
