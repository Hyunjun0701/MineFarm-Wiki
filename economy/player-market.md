# 유저거래소

유저거래소는 판매자가 아이템과 가격을 정해 다른 플레이어에게 판매하는 자유시장입니다.

## 판매 등록

`/유저거래`에서 거래소를 열고, 내 물건은 `/유저거래 내등록`에서 확인할 수 있습니다.

{% stepper %}

{% step %}
### 아이템 준비

판매할 아이템을 손이나 등록 화면에 준비합니다.
{% endstep %}

{% step %}
### 가격과 수량 입력

가격과 수량을 입력합니다.
{% endstep %}

{% step %}
### 등록 내용 확인

등록 전 아이템, 수량과 총가격을 다시 확인합니다.
{% endstep %}

{% step %}
### 내 등록 확인

등록 뒤 `내 등록` 화면에서 정상적으로 올라갔는지 확인합니다.
{% endstep %}

{% endstepper %}

등록된 아이템은 일반 인벤토리와 분리된 거래 보관 상태로 다뤄집니다.

## 목록 살펴보기

현재 거래 목록은 카테고리와 정렬을 이용해 탐색합니다. 가격이 싼 순서만 보지 말고 수량, 아이템 상태와 판매 조건을 함께 확인하세요.

검색이나 태그 입력 기능은 현재 유저거래소의 기본 탐색 방식이 아닙니다.

## 판매 완료·취소·만료

- 판매가 완료되면 대금 수령 상태를 확인합니다.
- 내 등록은 정해진 절차로 취소하고 남은 아이템을 회수합니다.
- 만료된 등록이 자동 우편으로 돌아온다고 가정하지 말고 `내 등록`에서 직접 상태와 회수 가능 여부를 확인하세요.

정확한 등록 한도와 판매 수수료는 등록 화면에 표시되는 현재 값을 기준으로 합니다.

## 현재 기본 운영값

2026년 9월 11일 서버 설정 기준입니다. 직업 효과나 별도로 적용된 혜택에 따라 개인별 표시가 달라질 수 있습니다.

| 항목 | 기본값 |
| --- | --- |
| 동시 등록 한도 | 7건 |
| 등록 유효 기간 | 7일 |
| 판매 성공 수수료 | 판매 금액의 5% |

{% hint style="warning" %}
**만료 물품도 등록 한도를 차지합니다**

새 등록이 막히면 `내 등록`에서 **만료 물품부터 회수**하세요. 수수료 조건은 등록할 때 정해지므로 등록 확인 화면의 예상 수령액을 확인하세요.
{% endhint %}
