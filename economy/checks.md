# 수표

수표는 MineValley의 공식 화폐 금액을 실물 아이템 형태로 전달하거나 보관할 때 사용하는 수단입니다.

## 할 수 있는 일

- 자신의 잔액으로 수표 발행
- 수표의 금액과 상태 확인
- 정상 수표 환전

## 안전하게 사용하기

- 발행 전에 금액을 다시 확인합니다.
- 받았을 때 표시된 금액과 상태를 확인합니다.
- 환전 중에는 수표를 옮기거나 같은 동작을 반복하지 않습니다.
- 문제가 생기면 수표를 버리거나 다시 거래하지 말고 인벤토리를 유지한 채 문의합니다.

복사되었거나 이미 처리된 수표는 정상 수표와 다르게 거절될 수 있습니다.
