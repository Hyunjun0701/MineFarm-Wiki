# 방랑가 전용 개인 주문

[주문소](public-orders.md) 안에서 이용하는 방랑가 전용 기능입니다. 납품할 플레이어 한 명을 지정해 주문을 만듭니다. 방랑가의 관련 해금 조건을 만족한 주문 작성자가 물품·수량·보상을 정합니다.

{% hint style="info" %}
**방랑가 50레벨 해금 기능**

주문 작성자는 정식 방랑가 50레벨의 전문 해금 조건을 만족해야 합니다. 현재 주직업과 주문 화면에서 실제 작성 가능 여부를 확인하세요.
{% endhint %}

## 일반 주문과의 차이

| 구분 | 일반 주문 | 방랑가 개인 주문 |
| --- | --- | --- |
| 납품 상대 | 조건을 만족하는 플레이어 | 지정한 상대 |
| 만드는 방법 | 주문소의 일반 주문 등록 | `/개인주문 <닉네임>` |
| 작성 조건 | 현재 주문 등록 조건 | 방랑가 관련 해금 필요 |

## 작성 순서

1. 주문을 납품할 상대의 정확한 닉네임을 확인합니다.
2. `/개인주문 <닉네임>`으로 상대를 지정합니다.
3. 등록 화면에서 품목·수량·보상을 정합니다.
4. 최종 화면의 상대 이름과 지급 금액을 다시 확인합니다.
5. 주문을 등록하고 주문 화면에서 진행 상태를 확인합니다.

자기 자신은 납품 대상으로 지정할 수 없습니다. 상대를 찾을 수 없거나 해금 안내가 나오면 닉네임과 현재 직업 상태를 확인하세요.

주문 작성자는 필요한 물품을 받는 쪽이고, 지정 상대는 물품을 납품하는 쪽입니다. 물품을 판매 등록하는 [유저거래소](player-market.md)와 구분해서 이용하세요.
