# 방랑가 전용 개인 주문

[주문소](public-orders.md)에서 납품할 플레이어 한 명을 지정하는 방랑가 전용 기능입니다. 물건을 받을 사람이 주문을 만들고, 지정된 상대가 물품을 납품합니다.

{% hint style="info" %}
**방랑가 50레벨 해금 기능**

주문을 만들려면 정식 방랑가 50레벨의 전문 해금 조건을 만족해야 합니다. 현재 주직업을 확인하고 주문 화면에서 작성할 수 있는지 살펴보세요.
{% endhint %}

## 일반 주문과의 차이

| 구분 | 일반 주문 | 방랑가 개인 주문 |
| --- | --- | --- |
| 납품 상대 | 조건을 만족하는 플레이어 | 지정한 상대 |
| 만드는 방법 | 주문소의 일반 주문 등록 | `/개인주문 <닉네임>` |
| 작성 조건 | 주문 화면에서 확인 | 정식 방랑가 50레벨 전문 해금 |

## 작성 순서

1. 주문을 납품할 상대의 정확한 닉네임을 확인합니다.
2. `/개인주문 <닉네임>`으로 상대를 지정합니다.
3. 등록 화면에서 품목·수량·보상을 정합니다.
4. 최종 화면의 상대 이름과 지급 금액을 다시 확인합니다.
5. 주문을 등록하고 주문 화면에서 진행 상태를 확인합니다.

{% hint style="warning" %}
등록 전에 **납품할 상대의 닉네임과 지급할 총보상**을 확인하세요. 자기 자신은 납품 대상으로 지정할 수 없습니다.
{% endhint %}

상대를 찾을 수 없다는 안내가 나오면 닉네임을, 해금 안내가 나오면 현재 주직업과 해금 조건을 확인하세요. 내 물건을 다른 플레이어에게 판매 등록하려면 [유저거래소](player-market.md)를 이용합니다.
