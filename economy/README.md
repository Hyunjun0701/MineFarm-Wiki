# 경제와 거래

MineFarm의 경제는 서버 상점만 이용하는 구조가 아니라, NPC 요청과 섬 활동, 유저 거래와 공개 주문이 서로 다른 선택지를 제공하는 구조입니다.

## 주요 경로

- NPC 상점에서 사고팔기
- [유저 거래](player-market.md)에 물품 등록하기
- [공개 주문](public-orders.md)을 만들거나 납품하기
- NPC·섬 퀘스트 완료하기
- [수표](checks.md)를 발행하거나 환전하기

## 기본 원칙

- 유저 거래 가격은 플레이어가 정합니다.
- 판매 경로마다 조건, 수수료와 보상 방식이 다를 수 있습니다.
- 등록·납품·수령 전에는 품목, 수량과 금액을 다시 확인하세요.
- 거래 중 문제가 생기면 같은 작업을 반복하기 전에 현재 상태를 확인하세요.

정확한 수수료와 한도는 실제 운영값 확인 후 각 문서에 공개합니다.
