# 경제와 거래

![농산물과 가공품, 기술 제품을 나누는 마을 시장 소개 일러스트](../assets/images/sections/economy-banner-v1.png)

처음 수확한 작물이나 채광한 광물을 팔고 싶다면 [주민 상점의 첫 판매 안내](npc-shops.md#first-sale)부터 확인하세요. 가격을 직접 정해 팔 때는 유저거래소, 필요한 물건을 주문할 때는 주문소를 이용합니다.

## 거래 경로 비교

| 경로 | 누가 조건을 정하나요? | 어울리는 상황 |
| --- | --- | --- |
| [주민 상점](npc-shops.md) | 서버 | 현재 취급하는 품목을 사고팔고 싶을 때 |
| [유저거래소](player-market.md) | 판매자 | 내 물건과 판매 가격을 정하고 기다릴 때 |
| [주문소](public-orders.md) | 구매자 | 필요한 물건과 보상을 먼저 제시할 때 |
| [주민 퀘스트](../residents/README.md)·[섬 퀘스트](../island-village/contribution-and-quests.md) | 주민 또는 마을 | 퀘스트에서 요구하는 물품을 납품할 때 |

## 기본 원칙

{% hint style="warning" %}
**확정 전에 품목·수량·총금액 확인**

- 상점이나 주문마다 취급하는 아이템이 다릅니다.
- 수수료, 한도와 보상 받는 방법을 확인하세요.
- 등록·구매·납품·수령 전에는 품목, 수량과 총금액을 다시 확인하세요.
- 거래 후에는 아이템 수량과 잔액을 확인하세요. 결과가 보이지 않으면 같은 버튼을 반복해서 누르지 마세요.

가격, 수수료와 한도는 거래하는 게임 화면에서 확인하세요.
{% endhint %}

## 어떤 거래부터 할까요?

아직 팔 물건이 없다면 [씨앗 구입](npc-shops.md#buy-seeds)부터 시작해 보세요. 이미 물건을 준비했다면 위 표에서 판매할 곳을 고르면 됩니다.

납품할 상대를 지정하는 개인 주문은 **주문소 안의 방랑가 전용 기능**입니다. 작성 조건은 [방랑가 전용 개인 주문 안내](public-orders.md#wanderer-private-orders)에서 확인하세요.

돈을 아이템으로 전달하려면 [수표](checks.md), 물건을 선물하려면 [우편함](../guides/storage-and-mail.md)을 이용합니다.
